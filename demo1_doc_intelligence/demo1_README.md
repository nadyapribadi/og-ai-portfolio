## Pipeline detail

### ingest.py

**Purpose:** Load PDFs → chunk → generate questions (Reverse HyDE) → embed → store in ChromaDB

**Key parameters:**
```python
chunk_size = 3500        # captures full pages with tables
chunk_overlap = 150      # prevents boundary information loss
TOP_K = 4                # chunks retrieved per query
GROQ_MODEL = "llama-3.3-70b-versatile"  # for question generation
MODEL_EN = "all-MiniLM-L6-v2"           # local embedding model
```

**Reverse HyDE:** At ingest, each chunk gets 5 questions generated by Groq 70B.
Questions prepended to chunk text before embedding. This bridges vocabulary gap
between user questions and technical document content.

**Table extraction:** pdfplumber extracts tables as structured arrays,
converted to markdown format with | column separators before embedding.
Critical for 456.pdf consequence tables (Tier 1/2 thresholds).

**Run:**
```bash
python demo1_doc_intelligence/src/ingest.py
# Takes ~10 minutes (246 chunks × 5 questions each via Groq API)
# Output: vectorstore_en/ and vectorstore_multi/ in data/
```

### retrieval.py

**Purpose:** Question → search → answer with citations

**Pipeline:**
1. `detect_language()` — langdetect library
2. `translate_to_english()` — deep-translator (Google Translate) if non-English
3. `load_vectorstore()` — loads ChromaDB with cached embedding model
4. `expand_query()` — Groq 8B generates 3 additional search variants
5. `search_chunks()` — MMR search across all 4 variants, deduplication
6. `build_context()` — formats chunks with source/page citations
7. Groq 70B answers with 7-rule strict system prompt

**Key models:**
```python
GROQ_MODEL_FAST  = "llama-3.1-8b-instant"      # query expansion
GROQ_MODEL_SMART = "llama-3.3-70b-versatile"    # answering
```

**System prompt rules (non-negotiable):**
1. Use ONLY the provided excerpts — no general knowledge
2. Cite every claim: (Source: filename, Page: N)
3. Prohibitions are complete answers — don't look for prerequisites
4. Never hedge falsely if answer IS in excerpts
5. Keep technical terms in English even in Bahasa answers
6. Show incomplete lists honestly
7. "Not found" if genuinely absent

## Known limitations (documented)

| Limitation | Root cause | Planned fix |
|-----------|-----------|------------|
| Multilingual disabled | Cross-lingual retrieval quality insufficient with all-MiniLM-L6-v2 | Translation approach (current) works better |
| Q4 "who wrote this" fails | Author info on page 1, semantic search doesn't retrieve it | Approach A: metadata extraction at ingest (iteration 2) |
| Very long documents (>40 pages) may have incomplete answers | Context window limit on Groq free tier (6000 TPM) | Increase TOP_K when on paid tier |
